# theuncommon.github.io

Portfolio site for Adam Carter-Groves, Senior Game System Designer: https://theuncommon.co.uk

Built with Jekyll on GitHub Pages.

- `index.html`: home page (hero, design pillars, projects, personal projects, contact).
- `DBM.html`: Death by Misadventure (personal projects) page.
- `_data/projects.yml`: all project entries. Add or edit projects here, not in the HTML.
- `_config.yml`: site title, description, email and LinkedIn link.
- `_layouts/default.html`: shared page shell (header, footer, meta tags).
- `assets/css/style.css`: styles. `assets/img/` and `assets/video/`: web-sized media.

Preview locally: `jekyll serve`, then open http://localhost:4000.
